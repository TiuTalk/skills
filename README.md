# skills

My personal Claude Code skills, installable via [skills.sh](https://skills.sh).

## Install

```bash
npx skills add TiuTalk/skills
```

## Skills

### brainstorm-prd

Walks through an adaptive interview about a feature or large change, then writes a Product Requirements Document (PRD).

### handoff

Writes a handoff document that lets a fresh Claude Code session resume the work with full context, instead of relying on /compact.

### tdd

Test-driven coding workflow for any language. Picks a mode (full loop, regression test first, spike, humble object, characterize legacy), decomposes work into a behavior list, then drives each item through 🔴 RED → 🟢 GREEN → 🔵 REFACTOR with status checkpoints. Rules and antipatterns each carry a "Why".
